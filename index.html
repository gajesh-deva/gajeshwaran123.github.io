Featured Project Tested & Working

🤖 AI Service Desk Agent

A no-code AI-powered Level 1 IT Service Desk assistant built using Claude and a custom IT Service Desk Knowledge Base. The agent is designed to classify issues, assess impact and urgency, provide safe troubleshooting guidance, recommend escalation and prepare accurate ticket information.

Claude AI No-Code AI Service Desk ITSM Windows Microsoft 365 ServiceNow Concepts Security

01 Project Overview

The AI Service Desk Agent demonstrates how an AI assistant can support common Level 1 Service Desk activities while following practical IT support, security and least-privilege principles.

02 Objective

The objective was to create a realistic Service Desk assistant that does not simply generate generic answers. It should identify the issue, ask useful diagnostic questions, classify the request, assess priority, provide safe troubleshooting and know when to recommend escalation.

06 Security & Safety Principles

✓ Never request passwords or MFA codes.
✓ Never bypass access controls.
✓ Apply least-privilege principles.
✓ Require appropriate approval for access.
✓ Escalate suspected security incidents.
✓ Never claim actions were completed without confirmation.
✓ Distinguish confirmed facts from assumptions.
✓ Avoid declaring major incidents without authorised confirmation.

07 Project Limitation

The current project does not have live ServiceNow, Active Directory, Entra ID, endpoint-management or other IT-system integrations. The agent therefore does not actually create tickets, unlock accounts, change permissions, install software or perform administrative actions. It provides recommendations and prepares ticket content for an authorised IT team to action.
