AI Service Desk Agent

● Tested

The AI Service Desk Agent is designed to simulate realistic Level 1 IT Service Desk behaviour. It identifies user issues, classifies incidents and service requests, assesses impact and urgency, recommends priorities, provides safe troubleshooting guidance, and prepares accurate ticket information.

The project focuses on practical IT Service Management, security, least privilege, accurate documentation, safe escalation, and avoiding false claims about actions the AI cannot actually perform.

🎯 Objective

Demonstrate how an AI assistant can support Level 1 IT Service Desk operations while following practical IT support, security and ITSM principles.

Security & Safety Principles

Never request or expose passwords or MFA codes
Never bypass access controls
Apply least-privilege principles
Require appropriate approval for access requests
Escalate suspected security incidents
Never claim an action was performed without confirmation
Separate confirmed facts from assumptions
Do not declare a major incident without authorisation

Current Project Limitation

The current project does not have live integration with ServiceNow, Active Directory, Microsoft Entra ID, endpoint-management platforms or other production IT systems.

The agent therefore does not actually create tickets, unlock accounts, change permissions, install software or perform administrative actions. Instead, it provides recommendations and prepares ticket content for an authorised IT team to action.
